# nexum/api

Deklarative REST-Ressourcen, Pagination, Filter und Problem Responses.

## Installation

    composer require nexum/api

## Öffentliche API

ApiResource, AbstractResourceController, ApiResponseFactoryInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
