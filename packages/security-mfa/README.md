# nexum/security-mfa

Verschlüsseltes TOTP und einmalige Recovery-Codes.

## Installation

    composer require nexum/security-mfa

## Öffentliche API

MfaManager, MfaSecondFactorGate. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
