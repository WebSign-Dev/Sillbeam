# nexum/http

Sichere Request-Metadaten und durchgängige Request-IDs.

## Installation

    composer require nexum/http

## Öffentliche API

ClientContextResolverInterface, ClientContext. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
