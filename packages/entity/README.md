# nexum/entity

Schlanke UUID-, Integer-, Timestamp- und Soft-Delete-Entity-Basen.

## Installation

    composer require nexum/entity

## Öffentliche API

EntityInterface, TimestampedInterface, SoftDeletableInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
