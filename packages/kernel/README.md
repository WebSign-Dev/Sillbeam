# nexum/kernel

Modulregistrierung, Discovery, Routing und Runtime-Informationen.

## Installation

    composer require nexum/kernel

## Öffentliche API

NexumKernel, ModuleRegistryInterface, KernelInformationInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
