# nexum/security-passkey

WebAuthn-Registrierung und passwortlose Authentifizierung.

## Installation

    composer require nexum/security-passkey

## Öffentliche API

PasskeyManager, WebauthnServer. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
