# nexum/pack-core

Metapaket für die verbindliche Nexum-Grundausstattung.

## Installation

    composer require nexum/pack-core

## Öffentliche API

Composer-Metapaket ohne Laufzeitcode. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
