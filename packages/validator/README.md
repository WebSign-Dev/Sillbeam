# nexum/validator

Wiederverwendbare generische Symfony-Constraints.

## Installation

    composer require nexum/validator

## Öffentliche API

StrongPassword. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
