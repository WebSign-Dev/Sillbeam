# nexum/logger

Strukturiertes Logging mit rekursiver Geheimnis-Redaction.

## Installation

    composer require nexum/logger

## Öffentliche API

ContextSanitizer, SafeLogger. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
