# nexum/filesystem

Provider-neutrale Speicherung mit sicheren relativen Pfaden.

## Installation

    composer require nexum/filesystem

## Öffentliche API

StorageInterface, LocalStorage, FlysystemStorage, SafePath. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
