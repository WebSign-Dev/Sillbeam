# nexum/messenger

Stabiler Dispatch-Contract auf Symfony Messenger.

## Installation

    composer require nexum/messenger

## Öffentliche API

MessageBusInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
