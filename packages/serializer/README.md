# nexum/serializer

Begrenzte JSON-Serialisierung mit Symfony Serializer.

## Installation

    composer require nexum/serializer

## Öffentliche API

SerializerInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
