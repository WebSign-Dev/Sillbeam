# nexum/management

Gemeinsame CLI- und API-Verwaltung von Nexum-Modulen.

## Installation

    composer require nexum/management

## Öffentliche API

ModuleConfigurationManager, ModuleAction, nexum:module. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Monorepo ausgeführt.
