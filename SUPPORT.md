# Support

Use [GitHub issues](https://github.com/WebSign-Dev/sillbeam-core/issues) for reproducible bugs and documentation questions. Check the [guides](docs/README.md) and [troubleshooting](docs/operations/troubleshooting.md) first.

Include the Sillbeam version/commit, PHP/Symfony versions, relevant configuration, application layout, expected/actual behavior and a minimal reproduction. Include architecture output if the container builds. Remove credentials, personal data and private paths from shared logs.

Sillbeam is maintained on a best-effort basis; there is no guaranteed response time or commercial support commitment. Sillbeam Core v0.2.0 is unreleased; after publication install it with `composer require websign-dev/sillbeam-core:^0.2.0`. The changelog records released versions. Before 1.0, consult release notes for compatibility changes.

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
