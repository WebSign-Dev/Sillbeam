# Modul: serializer

Begrenzte JSON-Serialisierung mit Symfony Serializer.

## Bereitstellung

Das Modul ist Bestandteil des Composer-Pakets `benjaminoeffinger/nexum` und wird nicht separat installiert.

## Öffentliche API

SerializerInterface. Symfony-Dienste bleiben dekorier- und konfigurierbar; interne Implementierungen sind kein Stabilitätsvertrag.

## Entwicklung

Tests, PHPStan, Architekturregeln und Coding Style werden zentral im Nexum-Package ausgeführt.
