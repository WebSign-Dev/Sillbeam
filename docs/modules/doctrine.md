# doctrine

Bei vorhandenem DoctrineBundle werden direkte Project-Entities und aktive Module mit nativen AttributeDriver-Mappings integriert. Dedizierte Treiber halten automatische Ausschlüsse lokal zu Nexum und erhalten manuelle native Mappings. `doctrine: false` schaltet die Integration aus. Es gibt keine Nexum-Entity-Basen, Stores, Filter oder Listener. [Konfiguration](../reference/configuration.md).
